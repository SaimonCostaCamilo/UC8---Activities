# A15 — Como executar

Requisitos: Python 3 e Tkinter (biblioteca padrão).

1. Abra o terminal nesta pasta.
2. Execute `python verificar.py`. O programa usa bancos temporários e não altera dados reais.
3. Execute `python main.py` para abrir a interface gráfica.
4. Produtos: selecione uma linha e use **Editar selecionado**; Salvar atualiza o mesmo ID. **Novo** inicia uma inclusão independente. Exclusão exige confirmação.
5. Clientes: cadastre e liste nomes fictícios.
6. Produtos e clientes ficam em `dados/mercado.db`; o pedido não é persistido.

Esta pasta contém somente os arquivos referentes à atividade A15. Os módulos de apoio necessários estão integrados nesta versão.
