# AULA07 — Modelos de domínio e testes automatizados

## Objetivo
Modelos de domínio e testes automatizados.

## Organização
- **Arquivos principais:** modelos.py e verificar.py.
- **Registro:** documento `registro-*.md` com arquitetura, testes, decisões e reflexão da atividade.
- **Recursos:** imagens e arquivos auxiliares permanecem nesta pasta quando utilizados.

## Como executar
Abra um terminal nesta pasta e execute o arquivo principal: `python arquivo_principal.py`.

## Como validar
python verificar.py.

## Boas práticas
- Execute os comandos a partir da pasta da aula para que os imports locais funcionem.
- Mantenha interface, regras de negócio, persistência e testes em módulos separados.
- Não misture arquivos de aulas diferentes; cada aula é um projeto independente.
