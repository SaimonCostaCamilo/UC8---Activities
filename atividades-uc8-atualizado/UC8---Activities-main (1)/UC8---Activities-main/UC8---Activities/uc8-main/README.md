# UC8 — Atividades

Repositório organizado por aula. Cada pasta `aulaNN` contém o código da atividade, seu registro e um README com instruções de execução.

| Aula | Projeto |
|---|---|
| 01 | Fundamentos de entrada, saída e cadastro |
| 02 | Cadastro completo e controle de estado |
| 03 | Conversão de moedas e cálculos monetários |
| 04 | Sistema escolar e cálculo de médias |
| 05 | Interfaces escolares com organização por grupos e janelas |
| 06 | Modelagem de aluno e validação de dados |
| 07 | Modelos de domínio e testes automatizados |
| 08 | Carrinho, pagamento e arredondamento decimal |
| 09 | Integração de interface, pedido e pagamento |
| 10 | Interface gráfica de pedidos e validações |
| 11 | Pizzaria: estados do pedido, prévia e confirmação |
| 12 | Mercado: catálogo, carrinho, pagamento e persistência JSON |

## Execução
Entre na pasta da aula desejada e siga o `README.md` local. Para projetos com interface gráfica, execute `python main.py`; para validar projetos com testes, execute `python verificar.py`. Na Aula 11, o projeto fica em `Aula 11/`.

## Requisitos gerais
- Python 3.10 ou superior.
- Tkinter para as interfaces gráficas (normalmente incluído na instalação do Python).
- Não há dependências externas obrigatórias para os projetos padrão.
